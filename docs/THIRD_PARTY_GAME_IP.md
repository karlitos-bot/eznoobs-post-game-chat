# EZNOOBS — Third-Party Game Names & Brand Assets

Internal release policy for references to games/publishers. This is a risk-reduction rule, not a legal opinion.

## Current safe default

EZNOOBS may identify supported games by plain text names and short text labels so users can choose the game they just played. The current `GameMark` implementation uses generic Lucide icons and text abbreviations rather than copied official game logos/artwork.

That is the preferred public-beta posture.

## Do not add by default

Without a clear licence, applicable legal basis, or publisher brand guideline that permits the use, do not add:

- official game logos;
- publisher logos;
- characters or splash art;
- weapon/skin artwork;
- screenshots used as branding;
- music/audio from a game;
- league/esports team marks;
- promotional key art;
- copied UI elements intended to imply official affiliation.

## Required public disclaimer

The Terms/Legal hub should continue to state in substance:

> EZNOOBS is an independent community service. References to games and publishers are for identification/context only and do not imply sponsorship, partnership, endorsement or affiliation unless expressly stated otherwise. Third-party marks remain the property of their respective owners.

## Before adding any official asset

1. Identify the actual rightsholder/publisher.
2. Find the current official community/brand/fan-content policy from the rightsholder.
3. Save the source URL/date and the exact permission relied upon.
4. Check whether commercial use, modified logos, screenshots, app icons or advertising use are prohibited.
5. If permission is ambiguous, use a generic EZNOOBS-made icon/text label instead.
6. Re-check permissions if the site starts monetising.

## EZNOOBS trademark/name work

Before major marketing spend:

- search `EZNOOBS`;
- search `EZ NOOBS`;
- search phonetic/visual variants;
- check EUIPO/TMview and relevant national/international databases;
- note relevant software, online communication/community and entertainment/service classes;
- obtain professional clearance if the project becomes commercially important.

A domain name alone is not trademark clearance.
